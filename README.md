# LuminaCore

**LuminaCore** เป็นปลั๊กอินหลักสำหรับเซิร์ฟเวอร์ Luminaris พัฒนาขึ้นโดยใช้ภาษา Kotlin ภายใต้ระบบโครงสร้างแบบโมดูลาร์ (Modular Architecture) โดยรวบรวมระบบอำนวยความสะดวก ระบบตรวจสอบเหตุการณ์เบื้องหลัง และคำสั่งลัดสำหรับการกดย่อตัวที่มีประสิทธิภาพสูงเข้าไว้ด้วยกันเป็นหนึ่งเดียว

## ⚡ ฟีเจอร์ทั้งหมดของระบบ (Features)
เนื่องจากตัวปลั๊กอินมีระบบย่อย (Module) มากกว่า 25 ระบบ ซึ่งประกอบไปด้วยหมวดหมู่หลักคือ:
- **System**: ระบบตรวจสอบความปลอดภัยหลังบ้านและส่งข้อมูลบันทึกผ่าน Discord Webhook
- **Activate**: ระบบสั่งงานและสลับโหมดการทำงานผ่านคีย์ลัดย่อตัว (Shift)
- **Features**: ระบบอำนวยความสะดวกในการเล่นและการแปลงสภาพบล็อกทางกายภาพ

## 📦 วิธีการติดตั้งและการใช้งาน
1. นำไฟล์ `LuminaCore.jar` ที่บิลด์สำเร็จไปวางลงในไดเรกทอรี `plugins/` ของเซิร์ฟเวอร์
2. ทำการสตาร์ทเซิร์ฟเวอร์ ปลั๊กอินจะโหลดตัวเองและสร้างไฟล์คอนฟิกแยกตามโมดูลย่อยลงในโฟลเดอร์ `plugins/LuminaCore/`
3. ผู้ดูแลระบบสามารถใช้คำสั่ง `/luminacore` ในเกมเพื่อเปิดหน้าต่าง GUI เพื่อเปิด/ปิดการทำงานของโมดูลย่อยทั้งหมดได้ทันที
4. พิมพ์คำสั่ง `/luminacore reload` เพื่อบังคับรีโหลดไฟล์ตั้งค่าของทุกโมดูลโดยไม่ต้องรีสตาร์ทเซิร์ฟเวอร์

## 🔨 วิธีการบิลด์ปลั๊กอินเอง (Building the Plugin)
คุณสามารถนำซอร์สโค้ดนี้ไปบิลด์ได้ด้วย Gradle โดยแยกออกเป็น 2 รูปแบบตามต้องการ:

### 1. การบิลด์แบบเต็ม (Full Build)
เป็นการบิลด์รวมทุกโมดูลเข้าด้วยกันเป็นไฟล์เดียว:
```bash
gradle build
```
ไฟล์ปลั๊กอินหลักจะอยู่ที่ `build/libs/LuminaCore.jar`

### 2. การบิลด์แบบเดี่ยว (Standalone Build)
เป็นการแยกบิลด์แต่ละโมดูลย่อยออกมาเป็นปลั๊กอินเดี่ยว ๆ อิสระจากกัน:
- **บิลด์ทุกโมดูลย่อยพร้อมกัน**:
  ```bash
  gradle jarAllStandalone
  ```
- **บิลด์เฉพาะโมดูลที่ต้องการ**:
  ```bash
  gradle jar[ชื่อโมดูล]
  ```
  *(ตัวอย่างเช่น `gradle jarAntiOp` หรือ `gradle jarTreeCapitator`)*

## 🔑 วิธีการข้ามการตรวจสอบลิขสิทธิ์ (Bypass License Verification)
หากต้องการเปิดใช้งานปลั๊กอินโดยไม่ต้องกรอกหรือเชื่อมต่อตรวจสอบคีย์ลิขสิทธิ์ ให้ปฏิบัติดังนี้ก่อนทำการบิลด์ปลั๊กอิน:
1. เปิดไฟล์ `LicenseManager.kt`
2. แก้ไขค่าตัวแปร `BYPASS` ให้เป็น `true`:
   ```kotlin
   private const val BYPASS = true
   ```
3. ดำเนินการบิลด์ปลั๊กอินตามปกติ ระบบการตรวจสอบคีย์จะถูกข้ามโดยสมบูรณ์
